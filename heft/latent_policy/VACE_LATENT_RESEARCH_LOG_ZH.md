## 目标与原则

从视频生成模型（Wan2.1-VACE-1.3B）里提取**有用、好学**的 latent，蒸馏给只看过去 33 帧和指令的学生（V-JEPA2 加各个读出头），**最终给策略用**（LIBERO，ACT / OpenWAM）。在这个前提下，读哪些头、怎么读、loss 的形式、学生的结构、轨迹用 Q·K 关系还是描述子，都可以重新讨论。

每个 latent 都按三条衡量：

1. **teacher 读数本身对不对**：用仿真真值（表面点轨迹、深度、物体标签）打分，真值只用于评测。
2. **学生学不学得会**：在没训练过的窗口上，学生输出离 teacher 有多近。
3. **对策略有没有用**：现阶段用动作 / 状态探针；之后做闭环评测。

另外还要看两点：学生的推理延迟，以及图像朝向要和 LeRobot 环境一致（仿真画面旋转 180°；tracking 数据和真值相对训练视频是水平镜像）。训练中**不使用**分割、GT mask 等外部数据。

## 当前结论

K 分区、prompt 物体级特征和 K-K 描述子跟踪是目前最有前景的三条线；原来的 Q·K 轨迹读法和原始 prompt 热图是主要问题；未来预测目前是最大的短板。数字来自 80 个带真值的留出窗口（详见评测体系）。

**10-15 补充（teacher）**

- **不依赖名词解析的 prompt 槽位可行**：加了"状态 + 指令"基线（0.13 / 0.27）后，启发式短语槽位是 0.36 / 0.62，按注意力选"最集中的 3 个词"是 0.31 / 0.58，相邻词合并出的 3 个槽是 0.32 / 0.54，全部内容词各自成槽是 0.31 / 0.48。以上每种相对基线的提升，95% 区间都不含 0。提升不是来自任务身份，而是来自物体的位置和运动。
- **RoPE 去高频只有小幅帮助，低频必须保留**：第三人称跟 7 步，去掉最高频 15–30% 的通道后物体误差从 7.8 降到 7.1–7.4 px，夹爪不变；反过来只保留高频半段，误差升到 14.4 px。跟踪靠的是低频通道。

**10-16 第一轮快速实验（只用 240 个窗口训练，在 80 个没见过的 episode 上评测）**

- **学生 latent 对策略的价值超过原始 V-JEPA**：基线 step 800 学生的全部 latent，探针 R² 为 0.37 / 0.60（动作 / 未来状态），比"状态 + 指令 + V-JEPA"高 +0.03–+0.16 / +0.02–+0.15，两个区间都不含 0。
- **学生的 prompt 槽位达到 teacher 水平**：基线 step 800 学生的短语槽位是 0.34 / 0.62，不依赖名词解析的"最集中 3 个词"是 0.32 / 0.57；teacher 分别是 0.36 / 0.62 和 0.31 / 0.58。
- **K-K 跟踪能泛化，前景轨迹 loss 让它更好**：第三人称观测段跟 7 步，学生 L15H7 的物体 / 夹爪误差 F0 为 11.8 / 8.2 px，F1 为 9.9 / 7.8 px，teacher L15H7 为 8.4 / 7.3 px，不动为 27.3 / 30.0 px。
- **未来段需要更多数据**：240 个窗口训出的学生在未来段只比不动好一点（F0 16.9 / 19.5 px，不动 20.9 / 22.0）；全量数据训练的基线 step 800 是 14.9 / 13.6。
- **逐词空间 loss 有效**：F4 的短语热图两两相关从 0.56 降到 0.46，短语槽位探针从 0.30 / 0.52 升到 0.32 / 0.57。腕部深度各组都在 0.74–0.76，只训腕部没有带来额外提升。
- **结构改动（F3）没有收益**；K-K 运动特征单独用对策略帮助有限。

**10-16 第二轮与未来预测诊断**

- **描述子目标（F5）是目前最明确的训练改进**：第三人称观测段跟 4 步，F5 的 track K 物体 / 夹爪误差 8.0 / 5.5 px，F0 13.6 / 12.3，基线 step 800 11.0 / 7.6，teacher 6.3 / 5.3；自匹配率 0.29（F0 0.43，teacher 0.11）。K 分区、prompt 和探针没有变差（短语槽位 0.31 / 0.52，F0 0.31 / 0.52）。
- **未来段仍接近不动**：F5 未来段跟 2 步 18.1 / 19.2 px，不动 20.9 / 22.0，teacher 6.6 / 4.3。所有学生的未来分支都没学会把内容搬到新位置。
- **短期未来主要是匀速**（第三人称，16 个窗口，从第 32 帧预测第 36 帧）：不动 14.9 px；用 28→32 帧真值速度匀速外推 4.5 px；用 24→28 帧真值速度 8.4 px；用 teacher 观测段 K 场估出的速度 9.8 px。到第 4 步（16 帧后）真值匀速也基本无效（37.9 vs 不动 44.7 px）；腕部相机上匀速比不动更差（物体 33.9 vs 22.6 px）。
- **速度估计本身准，主要损失是滞后一步**：teacher 观测段 K 场逐格速度和真值相比误差 3.5 px（物体平均每步移动 10.7 px）；相邻两段 4 帧的速度平均相差 4.7 px。观测分支最后一个读出时刻是第 28 帧，而第 32 帧已经在学生输入里。
- **怎么用**：匀速只当可推翻的初值（可学习增益 + 修正量），未来分支真正要学的是和匀速不同的部分（减速、接触、物体被带走），这也是未来 latent 对策略可能有额外价值的地方。

**10-16 G2（F6 配方 + 推移初始化 + 观测上下文；2k 缓存，8 卡，600 步）**

- **未来段第一次明显动起来**：第三人称未来段 K-K，第 1 / 2 / 3 / 4 步物体 / 夹爪误差 G2 为 7.1 / 6.9、15.9 / 13.5、17.4 / 15.4、25.9 / 23.4 px；F6 为 12.0 / 13.9、24.5 / 24.8、31.3 / 32.9、38.6 / 43.3；不动为 13.6 / 15.4、27.2 / 27.5、36.9 / 38.8、44.7 / 49.8；teacher 为 3.6 / 3.5、9.3 / 5.0、8.8 / 6.6、12.9 / 8.0。
- **不只是匀速**：G2 每一步都好于"滞后一步的真值匀速"（7.9 / 8.2、21.8 / 18.6…），第 3–4 步还好于"最新真值速度匀速"（23.4 / 23.1、37.9 / 34.5）；也好于它自己的匀速先验（第 1 步 10.6 / 11.5）。
- **观测段达到 teacher 水平**：第三人称观测段跟 4 步 track K 6.3 / 4.7 px，teacher 6.3 / 5.3，F6 8.0 / 5.6。
- **其他头也变好**：未来段 K L15H7 余弦 0.80（F6 0.71，基线 step 800 0.78），观测段 0.82；未来段逐词空间 KL 0.22（F6 0.27）；自匹配率未来段 0.36（F6 0.46，teacher 0.18）。
- **腕部相机的未来仍接近不动**，teacher 也一样。
- **归因有限**：没有 G0 对照，提升混有数据量（240 → 2000 个窗口）和 batch（16 → 64）的影响。但基线 step 800 用了全量数据、更多样本，未来段仍接近不动（track K 第 1 步 12.3 / 13.9），说明不只是数据的作用。
- **未来分支对策略有额外信息**（探针，观测 + 未来 vs 只用观测）：teacher 全部特征 +0.07–+0.17 / +0.05–+0.16，基线 step 800 学生 +0.08–+0.15 / +0.05–+0.16，区间都不含 0；240 窗口的 F0 / F1 不显著。注意观测特征只到第 28 帧，增量里可能有一部分来自第 32 帧而不是预测；G2 还没做探针。

**10-17 主线（G2 配方；完整缓存 6612 个训练窗口；8 卡；2000 步）**

- **约 1500 步到平台**：第 500 → 1000 → 1500 步各项持续变好，1500 → 2000 基本不变（如未来段 K-K 第 1 步 5.1 / 5.3 → 5.0 / 5.2 px，未来段 K L15H7 余弦 0.827 → 0.828）。按这个数据量，以后 1500 步（约 14 遍）就够。
- **观测段跟踪超过 teacher**：第三人称观测段 track K，第 1 / 4 步 3.6 / 2.9、6.8 / 5.5 px，teacher 4.3 / 4.1、8.5 / 6.5；beam 读法的真值误差 22.2 / 13.7，和 teacher 持平。
- **未来段继续变好**：第三人称未来段 track K 第 1 / 2 / 3 / 4 步 5.0 / 5.2、13.3 / 9.6、13.7 / 12.0、21.6 / 17.3 px（G2 7.1 / 6.9、15.9 / 13.5、17.4 / 15.4、25.9 / 23.4；teacher 3.6 / 3.5、9.3 / 5.0、8.8 / 6.6、12.9 / 8.0）。从第 2 步起好于最新真值速度匀速（14.8 / 11.8…），第 1 步接近（4.5 / 4.2）。和 teacher 的差距第 1 步约 1.5 px，第 4 步约 9 px。
- **其他头**：K 余弦观测段 0.908 / 0.836（L22H9 / L15H7），未来段 0.889 / 0.828（基线 step 800 为 0.867 / 0.794、0.853 / 0.783）；逐词空间 KL 观测段 0.111、未来段 0.201；短语热图两两相关在第 1000 步最好（0.417），之后略回升到 0.432。
- **深度**：腕部稳定（和 teacher 相关 0.83 / 0.86，和仿真深度的 Spearman 0.73 / 0.74，高于 teacher 的 0.66 / 0.71）；第三人称不训练，读数逐渐漂移（和 teacher 相关 0.56 → 0.46），不应使用。
- **还没测**：主线 checkpoint 对策略的探针。

探针只有 80 个留出窗口，置信区间较宽，差距在 0.05 以内的比较不作结论。prompt 物体级特征目前用"连续内容词"切分短语，只用于评测；正式版要换成不依赖名词解析的做法。

## 评测体系

所有评测都在同一批固定窗口上进行，teacher 和学生走同一套读出代码。

- **窗口**：训练 240 个（40 个任务 × 3 个 episode × 2 个视角）；留出 80 个，取自 tracking 数据集的 40 个验证 episode，带仿真表面点轨迹和深度。留出窗口的起始帧取 4 的倍数，保证每个读出时刻都有标注。基线和 B 在全量数据上训练过这些 episode，对它们而言衡量的是拟合。
- **轨迹**：同一批真值查询点（移动物体和夹爪，只统计位移超过 8 px 且 1 cm 的点），单位是 256 分辨率下的像素；以"完全不动"作参照。读法有两种：原来的 Q→K 加 beam，和 heft 式的 K-K 描述子跟踪（上采样、局部搜索 32 px、亚像素半径 8 px、EMA 0.05，可选 RoPE 频段筛选）。
- **K 分区、语义、深度**：K 余弦、逐格词分布 KL、逐词空间 KL、短语热图对比度、短语热图前 5% 落在物体上的比例（随机水平约 0.34），以及深度在物体格子上和仿真深度的 Spearman 相关。
- **策略探针**：用岭回归预测观测段之后 8 步的动作（56 维）和末端位移加夹爪状态（5 维），输入是本体状态加上各种 latent；在训练窗口上拟合，在留出窗口上算 R²，按 episode 做 bootstrap 置信区间，并和"状态 + 原始 V-JEPA"做配对比较。

局限：留出只有 80 个窗口；探针是线性的，只能说明信息是否容易读出，不等于闭环效果；短语切分是临时的启发式规则。
